Update `docs/PROGRESS.md` for this session:

1. Add a new entry at the top of **Log** with today's date: what was done (link files/PRs), and any decision with a one-line reason.
2. Update **Current state** if anything about prod, tests or docs changed. Run the tests to confirm the count.
3. Update **Next up**: tick or remove finished items, add new ones. Keep 3–5 items.
4. Add or resolve entries in **Open questions**.

Keep it concise. Don't log trivial steps. Then show me the diff.
